# Shift Code — Technik, Rechtliches und Launch-Checkliste


## Technisches Setup (Reihenfolge einhalten)

Schritt 1: E-Mail-Tool einrichten
Empfehlung: MailerLite (günstig, einfach, DSGVO-konform, Schweiz-freundlich)
Konto erstellen auf mailerlite.com
Absenderdomain verifizieren (deine eigene E-Mail-Domain)
Automatisierung aufsetzen: nach Opt-in startet Tag 1, dann jeden Tag einer

Schritt 2: Double Opt-in aktivieren
In MailerLite unter Einstellungen aktivieren
Bestätigungsmail anpassen: kurz, persönlich, in Petras Sprache
Bestätigungsseite anpassen: "Fast da. Check dein Postfach."

Schritt 3: Zahlungsanbieter
Empfehlung für die Schweiz: Stripe (einfachste Integration, CHF-fähig)
Alternative: Digistore24 (DE-basiert, fertige Infrastruktur, etwas höhere Gebühren)
Checkout-Seite aufsetzen, nach Zahlung Weiterleitung zur MailerLite-Anmeldung

Schritt 4: Datenschutzerklärung
Pflicht vor dem Launch
Generator verwenden: datenschutz-generator.de oder e-recht24.de (kostenlose Version reicht für Start)
Wichtige Punkte darin: E-Mail-Marketing, MailerLite als Auftragsverarbeiter, Stripe als Zahlungsdienstleister
Auf der Verkaufsseite verlinken

Schritt 5: Impressum
Pflicht auf jeder Website und in jeder E-Mail
Name, Adresse, E-Mail-Adresse von Petra
Auf der Verkaufsseite sichtbar verlinken

Schritt 6: E-Mails in MailerLite hochladen
Alle 30 E-Mails als Automation hinterlegen
Tag 1 startet 1 Tag nach Opt-in-Bestätigung
Jeden Tag eine E-Mail, 7 Uhr morgens

Schritt 7: Verkaufsseite live schalten
Empfehlung: Einfache Landing Page mit Carrd (günstig) oder direkt in MailerLite
Verkaufsseite aus outputs/shift-code-verkaufsseite.md verwenden
Kaufbutton verlinkt zu Stripe-Checkout


## Rechtliche Pflichtangaben in ALLEN E-Mails (bereits eingebaut)

Jede E-Mail enthält: "Shift Code ersetzt keine Therapie oder medizinische Behandlung."
Jede E-Mail hat automatisch einen Abmeldelink (MailerLite generiert das)
Keine therapeutischen Versprechen, keine Heilungsgarantien
Erfolge immer als Möglichkeit formulieren, nicht als Garantie


## Launch-Reihenfolge

Woche 1 vor Launch: Telegram-Kanal aufsetzen, erste Aufwärm-Posts veröffentlichen (Post 1 und 2 aus shift-code-telegram.md)

Woche 2 vor Launch: Weitere Posts (Post 3 und 4), Vorfreude aufbauen, Liste wachsen lassen

Launch-Tag: Post 5 auf Telegram, Verkaufsseite live, E-Mail an bestehende Kontakte wenn vorhanden

Nach Launch: Wöchentliche Begleitposts auf Telegram für aktive Teilnehmer


## Preise und Struktur (festgelegt)

Shift Code 30 Tage: CHF 97 einmalig
Shift Code mit Community: CHF 147 einmalig (Community noch aufzubauen)
Monatliche Membership als Upsell: CHF 27 pro Monat (spätere Phase)
