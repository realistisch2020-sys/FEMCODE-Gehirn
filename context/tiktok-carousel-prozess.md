# Prozess: Emotionale Carousel-Posts für Bücher

Aus dem KDP-Kurs, Ende Juli 2026 gesichert. Für jedes künftige Buch anwenden,
wenn TikTok-/Instagram-Carousels gebraucht werden.

Ein Carousel hat eine einzige Aufgabe: ab Slide 1 emotional so abholen, dass
weitergewischt wird. Jede Slide ist ein eigener Winkel auf das Thema — immer
emotional, nie sachlich.

## Slide-Struktur (6–10 Slides)

- **Slide 1 — Der sofortige Treffer:** löst in Sekunden eine starke Emotion
  aus (Wiedererkennung, Schmerz, Wut, Überraschung). "Das bin ich." Direkt
  rein in den Moment, keine Einleitung.
- **Slides 2 bis X — Emotionale Vertiefung:** jede Slide ein anderer Winkel
  desselben Themas, aufbauend, immer emotional.
- **Letzte Slide — Auflösung und Hoffnung:** eine Erkenntnis oder ein Gefühl
  von Stärke, emotionale Landung, kein harter CTA.
- Eine separate CTA-Slide mit dem Buchcover wird **einmalig** erstellt und an
  jedes Carousel angehängt — nicht Teil der eigentlichen Slide-Entwicklung.

## Ablauf

1. **Projektinfos:** Buchthema, Angle, Zielgruppe (eigene Sprache), stärkste
   Emotionen des Themas, welcher konkrete Aspekt in diesem Carousel behandelt
   wird, gewünschte visuelle Stimmung, Farbschema, Bildstil (fotorealistisch,
   Comic, illustriert, Aquarell, cinematisch …)
2. **Slide-Struktur:** je Slide Nummer/Name, ausgelöste Emotion, Text
   (max. 1–2 Sätze, wird später manuell in Canva eingefügt)
3. **Bildgenerator-Prompts** je Slide: nur visuell beschreiben (Motiv,
   Personen, Umgebung, Licht, Farben, Atmosphäre), kein Text im Bild, kein
   technischer Kram, gewählter Bildstil fliesst in jeden Prompt ein, Englisch

## Format der fertigen Übergabe

```
Slide [Nummer] — [Name]
Text für Canva: [Text]
Bildgenerator-Prompt: [Englischer Prompt]
```
