# Canva-Workflow: Instagram & TikTok Karussells

Verifiziert über Canva Help (Stand: 27.07.2026). Gilt für Canva Pro.

## 1. Konten verbinden (einmalig, nur ich selbst kann das — Login nötig)

1. Design im Editor öffnen → **Teilen**.
2. **Mehr** wählen, um alle Plattformen zu sehen.
3. **Instagram** bzw. **TikTok** auswählen.
4. Anmelden und Verbindung bestätigen.
5. Für ein weiteres Konto derselben Plattform: **Neues Konto verbinden**.

Claude kann diesen Schritt nicht übernehmen — die Anmeldung läuft über meinen eigenen Instagram/TikTok-Login, nicht über einen API-Key.

## 2. Karussell erstellen

- Karussell = ein Design mit mehreren Seiten (Slides) in Canva.
- Format: Instagram-Post 1080×1350 (4:5, Hochformat) läuft am besten im Feed.

## 3. Veröffentlichen / Planen

**Direkt beim Teilen:**
1. Design öffnen → **Teilen** → **Mehr** → **Planen** (Schedule).
2. Datum/Uhrzeit wählen → **Weiter**.
3. Kanal wählen (Instagram/TikTok).
4. Bei mehrseitigem Design: gewünschte Seiten für den Post auswählen.
5. Bildunterschrift eingeben → **Planen**.

**Über den Content Planner:**
1. Startseite → **Mehr** → **Content Planner**.
2. Inhalte im Kalender planen und veröffentlichen.

## 4. Automatisierung für viele Karussells auf einmal

- **Bulk Create**: aus einer Tabelle/Datenquelle automatisch viele Design-Varianten erzeugen. Zu finden im Editor unter **Apps → More from Canva**. Verfügbar für Desktop, u. a. für Social-Media-Formate.
- **Magic Switch** und eine öffentliche **API** zur vollautomatischen Planung/Veröffentlichung sind laut Canva Help aktuell nicht zuverlässig dokumentiert bzw. nicht für diesen Zweck vorgesehen — nicht verlässlich einsetzbar.

## Was Claude direkt im Canva-Account übernehmen kann

- Karussell-Designs/Vorlagen erstellen (Inhalt, Layout, Branding).
- Ordner anlegen und Designs organisieren.
- Vorhandenes Brand Kit nutzen (aktuell verbunden: "Instagram").

## Grenzen

- Instagram/TikTok-Konto verbinden: manuell, Login erforderlich.
- Planen/Veröffentlichen im Content Planner: manuell im Canva-Interface (kein Automatisierungs-Tool dafür angebunden).
- Bulk Create läuft nur im Canva-Editor selbst, nicht extern steuerbar.
