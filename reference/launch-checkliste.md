# Launch-Checkliste neues Buch

Ein Schritt nach dem anderen. Häkchen erst, wenn erledigt und geprüft.

## A. Inhalt
- [ ] Manuskript prüfen (Struktur, Lesefluss, Versprechen des Titels eingelöst, Backmatter mit Hinweis auf andere Bücher + Bonus-QR)
- [ ] Titel
- [ ] Untertitel
- [ ] Beschreibung (Hook, Schmerz, Versprechen, Inhalt, für wen)
- [ ] 7 Keywords
- [ ] Kategorien
- [ ] Cover (TB + Kindle, Wirkung als Thumbnail prüfen)

## B. KDP
- [ ] Preis Kindle / Taschenbuch
- [ ] KDP Select / Kindle Unlimited ja/nein
- [ ] Kindle veröffentlicht → ASIN
- [ ] Taschenbuch veröffentlicht → ASIN
- [ ] Beide Formate verknüpft
- [ ] Direktlinks (amazon.de/dp/ASIN) notiert in `context/business.md`

## C. Produktseite
- [ ] Produktseite live geprüft
- [ ] A+ Content + Bildmodule eingereicht, Freigabe abgewartet
- [ ] Autorenseite verknüpft

## D. Tracking & Bonus
- [ ] TAG-Namen nach Schema in `outputs/kanaele-und-attribution.md` (Kürzel B7)
- [ ] Tentary-Bonus angelegt, QR/Link im Buch funktioniert

## E. Launch-Werbung (alles kostenpflichtige erst nach Freigabe)
- [ ] Rezenzo: Buch anlegen, Rezensionsexemplare
- [ ] Amazon Ads: AUTO + EXACT + ASIN (Ziel-ASINs inkl. eigene Bücher), kleine Startgebote
- [ ] Meta Ads mit Tag
- [ ] Social Launch (Instagram, Facebook, Telegram) mit Tags
- [ ] Cross-Selling: neues Buch in Backmatter/Ads der anderen Titel

## F. Messung
- [ ] Tag 3, 7, 14: Verkäufe je Format, Ads-Kennzahlen, Rezensionen
