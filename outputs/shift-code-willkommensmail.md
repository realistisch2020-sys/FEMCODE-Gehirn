# Shift Code — Willkommensmail (nach Kauf, vor Tag 1)

Betreff: Du hast es. Shift Code startet morgen früh.

Hallo,

du hast gerade etwas Wichtiges getan. Nicht weil du eine E-Mail-Sequenz gekauft hast. Sondern weil du gespürt hast, dass es Zeit ist. Für etwas Echtes. Für den echten Shift.

Shift Code startet morgen früh direkt in deinem Postfach. Jeden Tag eine Einheit. Kurz, klar, direkt anwendbar. Kein Login, keine App, nichts zu installieren. Einfach morgen früh dein Postfach öffnen.

Eine Bitte: Leg das Postfach nicht stumm und verschieb es nicht. Die Wirkung kommt durch Konstanz. Fünf bis zehn Minuten täglich, über 30 Tage. Das ist alles, was es braucht.

Wenn du Fragen hast, erreichst du mich unter [E-Mail-Adresse eintragen].

Auf den Shift, der auf dich wartet.

Petra

Shift Code ist kein Ersatz für Therapie oder medizinische Behandlung. Es ist ein Selbstentwicklungsprogramm für Menschen, die bereit sind tiefer zu gehen. Bei ernsthaften psychischen Beschwerden wende dich bitte an eine Fachperson.
